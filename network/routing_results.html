2. What the algorithm is doing

Each route update is calculated from the remaining available links.

01 · SEARCH

A* scores possible paths

It combines the cost already traveled (g) with an estimate to the destination (h).

02 · DETECT

Unavailable links are excluded

A failed link or node is treated as unavailable for future route searches.

03 · SWITCH

Registered routes refresh

The router automatically recalculates active routes and uses the backup when possible.
